# Лабораторна робота №13 — Основи створення серверної і клієнтської програми CORBA

**Варіант:** 9 (клас «Матриця» з табл. 14.1 навчального посібника)  
**Середовище розробки:** Borland C++ Builder 6 та Borland VisiBroker 4.5  

## Структура проєкту
1. **`CORBA_Server/`** — серверна частина розподіленого додатку:
   - `MatrixServ.idl` — опис модуля `MatrixModule` та інтерфейсу `MatrixObj` мовою IDL;
   - `MyServer.h`, `MyServer.cpp` — реалізація інтерфейсу `MatrixImpl` на основі класу `Matrix`;
   - `Server.cpp` — головний файл консольного сервера CORBA.
2. **`CORBA_Client/`** — клієнтський Win32-додаток:
   - `ClientProject.cpp` — ініціалізація ORB/BOA та запуск форми клієнта;
   - `ClientUnit.h`, `ClientUnit.cpp`, `ClientUnit.dfm` — графічний інтерфейс клієнта для введення елементів матриці $2 \times 2$, скаляра $\alpha$ та отримання результатів від сервера CORBA.
